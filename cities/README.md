# City workspace

Each city is self-contained:

- `index.html` — the city landing page, when one has been built.
- `assets/` — every image, video, local note, and neighborhood-specific item for that city.

Current pages: Manteca, Mountain House, Lathrop, River Islands, and Woodbridge. River Islands and Woodbridge are communities inside Lathrop and Manteca, but each has its own page and assets, so each gets its own folder here.

Jack's main homepage (the Tracy-based page) lives in `../home/`, not here — it publishes as the site root `index.html`.
